# Проверка страницы прошивки на плате

Протокол ручной проверки change'а `web-flash-page` (задачи 7.x в его `tasks.md`). Пункты, которые
здесь закрываются, перечислены в `MANUAL` файла `test/spec_coverage/spec_coverage_data.py`: без
браузера, оснастки и живого чипа их не проверить автотестом. Порядок пакетов, отказы до записи и
чтение проверены на ПК на поддельной оснастке (`test/web/`).

## Что нужно

- Оснастка с прошивкой этой ветки (команда `erase` уже есть), провода по `README.md`.
- Плата с PY32F002B, питание 3,0–3,6 В.
- Файл прошивки платы `.hex` (из PlatformIO: `.pio/build/<env>/firmware.hex`), файл 128 Б для USER
  OTP и такой же с замком — `test/fixtures/otp.hex` и `otp_lock.hex`.
- Chrome на Windows и на macOS, Firefox.
- Страница: `https://waterius.github.io/esp32s3_swd_flasher/` после публикации (задача 6.1) или
  `python3 -m http.server -d docs 8000` и `http://localhost:8000/`.

## 7.1 Подключение

- [ ] Первый раз: «Подключить» → в окне Chrome виден только порт оснастки → выбрать → в строке
  «Чип» — `не выбран`; выбрать `py32f002b` → «Чип: py32f002b». Закрывает:
  `web-flash/Подключение к оснастке/Первое подключение`.
- [ ] 10 раз «Подключить» и «Отключить» — в логе ни разу нет строк старта оснастки (`# команды:`),
  чип тот же, `baud` тот же. Windows и macOS. Закрывает:
  `web-flash/Подключение к оснастке/Подключения не перезагружают оснастку`.
- [ ] При открытом `pio device monitor` «Подключить» — «порт занят: закройте монитор и gdb»
  (Windows; на macOS порт может открыться — записать, как вышло).
- [ ] Выдернуть USB оснастки — «оснастка отключена», кнопки неактивны.

## 7.2 Прошивка

- [ ] Файл прошивки и `otp.hex` вместе → «Прошить» → «Итог: ок», в строках итога — `# итог: ок` и
  первые строки лога платы. Закрывает: `web-flash/Прошивка за один сеанс/Прошивка и OTP`.
- [ ] Файл прошивки и `otp_lock.hex` → «Итог: ошибка — замок OTP не ставится»; чтение
  `0x08000000`, 16 Б до и после одинаково.
- [ ] Записать в страницу 100 данные (`gdb`: `load` файла на `0x08003200`), затем на странице
  отметить «Стереть всю основную flash» и прошить образ на страницы 0–9 → «Итог: ок»; чтение
  `0x08003200`, 128 Б — все `FF`; чтение `0x1FFF0280`, 128 Б — как до стирания. Закрывает:
  `web-flash/Прошивка за один сеанс/Полное стирание`.
- [ ] `erase` в строке команд — `# полное стирание: …`, `# проверка 0xFF: …`, `# итог: ок`, затем
  первые строки платы (плата пустая — их может не быть).
- [ ] Время прошивки одного образа со страницы и из PlatformIO — в design change'а, «Результат».

## 7.3 Лог, команды, память

- [ ] `reset` — `# сброс платы`, затем первые строки лога платы. Закрывает:
  `web-flash/Лог платы и команды/Перезапуск платы со страницы`.
- [ ] `info` — чип, IDCODE, UID, HSI.
- [ ] Область `flash 0x1FFF0280, 128 Б` → «Прочитать» — 8 строк, совпадают с `otp.hex`.

## 7.4 Браузер и сеть

- [ ] Firefox — вместо кнопок «Нужен Chrome или Edge на компьютере». Закрывает:
  `web-flash/Страница без установки программ/Браузер без Web Serial`.
- [ ] Chrome, инструменты разработчика, вкладка «Сеть»: после загрузки страницы прошить плату —
  новых запросов нет. Закрывает: `web-flash/Страница без установки программ/Нет сетевых запросов`.

## Результат прогона

Дата, ОС и браузер, версия оснастки (коммит), плата, что не сработало — сюда и в design change'а,
раздел «Результат».
