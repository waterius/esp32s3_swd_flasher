# Проверка страницы прошивки на плате

Протокол ручной проверки change'а `web-flash-page` (задачи 7.x в его `tasks.md`). Пункты, которые
здесь закрываются, перечислены в `MANUAL` файла `test/spec_coverage/spec_coverage_data.py`: без
браузера, программатора и живого чипа их не проверить автотестом. Порядок пакетов, отказы до записи и
чтение проверены на ПК на поддельном программаторе (`test/web/`).

## Что нужно

- Программатор с прошивкой этой ветки (команда `erase` уже есть), провода по `README.md`.
- Плата с PY32F002B, питание 3,0–3,6 В.
- Файл прошивки платы `.hex` (из PlatformIO: `.pio/build/<env>/firmware.hex`), файл 128 Б для USER
  OTP и такой же с замком — `test/fixtures/otp.hex` и `otp_lock.hex`.
- Chrome на Windows и на macOS, Firefox.
- Страница: `https://waterius.github.io/jaffa_flasher/` после публикации (задача 6.1) или
  `python3 -m http.server -d docs 8000` и `http://localhost:8000/`.

## 7.1 Подключение

- [x] Первый раз: «Подключить» → в окне Chrome виден только порт программатора → выбрать → в строке
  «Чип» — `не выбран`; выбрать `py32f002b` → «Чип: py32f002b». Закрывает:
  `web-flash/Подключение к программатору/Первое подключение`.
- [ ] 10 раз «Подключить» и «Отключить» — в логе ни разу нет строк старта программатора (`# команды:`),
  чип тот же, `baud` тот же. Windows и macOS. Закрывает:
  `web-flash/Подключение к программатору/Подключения не перезагружают программатор`.
- [ ] При открытом `pio device monitor` «Подключить» — «порт занят: закройте монитор и gdb»
  (Windows; на macOS порт может открыться — записать, как вышло).
- [ ] Выдернуть USB программатора — «программатор отключён», кнопки неактивны.

## 7.2 Прошивка

- [ ] Файл прошивки и `otp.hex` вместе → «Прошить» → «Итог: ок», в строках итога — `# итог: ок` и
  первые строки лога платы. Закрывает: `web-flash/Прошивка за один сеанс/Прошивка и OTP`.
- [ ] Файл прошивки и `otp_lock.hex` → «Итог: ошибка — замок OTP не ставится»; чтение
  `0x08000000`, 16 Б до и после одинаково.
- [x] Записать в страницу 100 данные (`gdb`: `load` файла на `0x08003200`), затем на странице
  отметить «Стереть всю основную flash» и прошить образ на страницы 0–9 → «Итог: ок»; чтение
  `0x08003200`, 128 Б — все `FF`; чтение `0x1FFF0280`, 128 Б — как до стирания. Закрывает:
  `web-flash/Прошивка за один сеанс/Полное стирание`.
- [x] `erase` в строке команд — `# полное стирание: …`, `# проверка 0xFF: …`, `# итог: ок`, затем
  первые строки платы (плата пустая — их может не быть).
- [ ] Время прошивки одного образа со страницы и из PlatformIO — в design change'а, «Результат».

## Результат прогона

Дата, ОС и браузер, версия программатора (коммит), плата, что не сработало — сюда и в design change'а,
раздел «Результат».

- 2026-11-13, macOS, Chrome, `a27e0d2`, плата Саши. §7.5 — всё прошло (прошивался один `node.hex`:
  OTP не писали). Прошивка со страницы — «Итог: ок» за 2,1 с, сеть пуста. Подробно — design
  `openspec/changes/archive/2026-11-13-web-flash-page/` и `…-jaffa-flasher-page/`, «Результат».
  Полное стирание: метка в странице 176 (вне образа) после прошивки с галочкой — `0xFF`, USER OTP
  та же (пустая), плата стартовала; прогон — уже со страницы на GitHub Pages. `erase` командой —
  вся flash `0xFF` за 0,4 с. Неотмеченное выше не проверялось: Windows, Firefox, USER OTP и замок,
  «порт занят», выдернутый USB. 10 переподключений со страницы требуют выбора порта руками — проверены
  открытием порта из Python.
