## Бизнес-процесс

Термины «Программатор Jaffa Flasher», «Плата», «Чип», «Образ», «USER OTP», «Лог платы», «Протокол gdb», «Сеанс
SWD» и «Итог» — в `business.md` change'а `swd-flash-py32f002b`, в реестр ещё не перенесены.

### Как сейчас

После change'а `swd-flash-py32f002b` плату шьют через программатор Jaffa Flasher только из PlatformIO или командой
gdb из его тулчейна (БТ/swd-flash-py32f002b/1, ещё не в реестре). Значит, на ПК нужен PlatformIO,
а человек должен уметь им пользоваться. Попробовать программатор без среды разработчика нельзя.
Стереть всю основную flash программатор не умеет: он пишет только страницы образа.

Объём: одна плата за раз, по одной прошивке на плату.

### Как станет

- **Страница прошивки** открывается по ссылке в Chrome или Edge, ничего не устанавливая
  (владелец, 2026-11-12). Человек подключает программатор к USB, выбирает его порт на странице, а на
  странице:
  - выбирает файлы Intel HEX: прошивку и, если нужно, данные для USER OTP;
  - отмечает, стереть ли перед записью всю основную flash;
  - нажимает «Прошить» и видит итог программатора и первые строки лога платы;
  - смотрит лог платы, вводит команды программатора, читает память чипа.
- Страница живёт в этом репозитории и публикуется на GitHub Pages; репозиторий станет публичным
  (владелец, 2026-11-12).
- Страница об изделиях ничего не знает: она пишет любые файлы по их адресам, как и программатор
  (БТ/swd-flash-py32f002b/2, ещё не в реестре).
- Завод шьёт со **страницы изделия**. Её делает изделие в своём репозитории: она берёт данные для
  USER OTP откуда нужно изделию и говорит с программатором так же, как страница прошивки.

### Эффект и цена

- Попробовать программатор и прошить плату может любой, у кого есть Chrome или Edge и программатор: без
  PlatformIO и без программ на ПК.
- Страница изделия не пишет прошивальщик заново: протокол и правила уже в программаторе, а разговор с
  ним показан страницей прошивки.
- Цена разработки и сопровождения страницы — открытый вопрос.

## Бизнес-требования

### Добавлено

#### БТ/web-flash-page/1. Прошивка из браузера без программ на ПК

Человек прошивает плату через программатор со страницы в Chrome или Edge и ничего не устанавливает на
ПК, даже PlatformIO (владелец, 2026-11-12). Страница пишет и основную flash, и USER OTP — те же
правила, что у прошивки из PlatformIO. Браузеры без Web Serial (Firefox, Safari) не поддержаны.

**Зачем:** любой может проверить программатор и прошить плату без среды разработчика. Изделие
строит свою заводскую страницу на том же разговоре с программатором, а не на своём прошивальщике.

#### БТ/web-flash-page/2. Полное стирание основной flash

Человек может перед записью стереть всю основную flash чипа, чтобы на плате не осталось ничего,
кроме нового образа. USER OTP при этом не стирается.

**Зачем:** с производства плата выходит чистой: без данных прошлых прошивок и проб. Программатор по
умолчанию данные вне образа сохраняет (БТ/swd-flash-py32f002b/2, ещё не в реестре) — стирание
делается только по явной команде.

## Границы

- Установка прошивки самого программатора из браузера — не здесь. Пока программатор прошивают из
  PlatformIO (открытый вопрос ниже).
- Нет данных для каждой платы (ключи, серийные номера), нет связи с сервером изделия, нет
  учёта прошитых плат — это страница изделия.
- Нет отладки и нет option bytes.
- Только Chrome и Edge на компьютере: только в них есть Web Serial.
