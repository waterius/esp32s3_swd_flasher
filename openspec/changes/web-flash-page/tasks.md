## 5. Команда `erase` в оснастке

Только после реализации `swd-flash-py32f002b`: команда встраивается в его модули.

- [x] 5.1 Описание и действие чипа: отметка области «основная» в `core/chip.h` и
  `chips/py32f002b_desc`; «стереть основное» в `chips/py32f002b_ops` по RM §4.2.3.4 —
  `MER | EOPIE`, запись слова, `BSY` до 50 мс, `WRPERR`, `EOP` (design §8).
- [x] 5.2 Шаг в `core/write`: стереть основное, проверить `0xFF` по всей области; тест на
  поддельном чипе, в том числе с `WRPERR`. Сценарии «стирание перед записью», «стирание при
  защите записи».
- [x] 5.3 Команда: `erase` строкой и через `monitor`, свой сеанс вне gdb; удачное `erase` —
  удачная запись для `vKill`; пустая строка пропускается. Строки `chip` и итога — в формате,
  который разбирает страница (design §5). Тесты в `test_console` и `test_gdb`: сценарии
  «только стирание», «пустая строка».
