## ADDED Requirements

### Requirement: Области чипа в ответе chip

Когда чип выбран, ответ на `chip` и на `chip <имя>` SHALL после строки `# чип: <имя>` перечислять
записываемые области выбранного чипа строками `# область <начало>–<конец>: <имя>` (адреса hex с
`0x`, конец включительно), у основной flash — с припиской `, основная`. Имя области — для людей:
у `py32f002b` это `flash` и `USER OTP`. Об изделиях строки ничего не говорят.
(БТ/jaffa-flasher-page/3)

#### Scenario: Области py32f002b

- **GIVEN** программатор запущен
- **WHEN** человек вводит `chip py32f002b`
- **THEN** программатор отвечает `# чип: py32f002b`,
  `# область 0x08000000–0x08005FFF: flash, основная`,
  `# область 0x1FFF0280–0x1FFF02FF: USER OTP` (проверяется тестом на ПК)
