## 1. Программатор: области в `chip`, формат лога

Термины: «область» — `chip::Region`, её имя для людей — `title`; «формат кадра» — биты данных,
чётность, стоповые биты UART лога платы (design §4, §7).

- [x] 1.1 Имя области USER OTP как в RM: `title` области `otp` — `USER OTP`; правка текстов
  «OTP не стёрлась» в спеке и design `swd-flash-py32f002b` и в `test_write` (design §4).
- [x] 1.2 Ответ `chip` перечисляет записываемые области: строки `# область <начало>–<конец>: <имя>[,
  основная]` в `core/commands`; тест `test_commands` по сценарию «Области py32f002b».
- [x] 1.3 Формат кадра в `baud`: разбор `[5-8][NEO][12]` в `core/commands`, `Host` —
  `get_log`/`set_log`, ответ `# лог: <скорость> <формат>`; тесты на сценарии «Другой формат
  кадра», «Неверный формат», «Неверная скорость» (design §7).
- [x] 1.4 `main.cpp`: `Serial1.end()`/`begin()` с `SERIAL_*` по формату; `pio run -e esp32s3`.
