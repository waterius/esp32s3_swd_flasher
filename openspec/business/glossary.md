# Глоссарий предметной области

Термины отсюда едут в спеки, имена таблиц, ручек и подписи в UI **без
переименований**. Термин, впервые появившийся в спеке или design, — ошибка:
его место здесь.

Наполняется переносом из `business.md` архивируемого change'а. Как устроен
процесс — `README.md` рядом.

| Термин | Что это | Откуда |
|---|---|---|
| Программатор Jaffa Flasher | ESP32-S3 Super Mini с прошивкой этого репозитория и проводами к плате; пишет МК PY32 на плате по SWD. В отличие от ST-Link или CMSIS-DAP, ему не нужны драйвер и программа прошивки на ПК: разработчику хватает PlatformIO, остальным — браузера. Прежде называлось «оснастка» (владелец, 2026-11-12) | `swd-flash-py32f002b`, `jaffa-flasher-page` |
| Плата | Плата с чипом, который прошивают | `swd-flash-py32f002b` |
| Чип | Тип микроконтроллера на плате, его имя программатору называют командой `chip`, например `py32f002b`. От чипа зависят адреса памяти, способ записи и проверка идентификатора | `swd-flash-py32f002b` |
| Протокол gdb | Протокол, которым gdb говорит с отладчиком (GDB Remote Serial Protocol). Программатор отвечает на нём как отладчик Black Magic Probe, поэтому PlatformIO шьёт через него штатно | `swd-flash-py32f002b` |
| Режим порта | Текстовый режим — лог платы и команды человека строками; режим gdb — пакеты протокола gdb. Программатор переключает их сам | `swd-flash-py32f002b` |
| Образ | Байты, которые ПК прислал программатору для записи за один раз, с их адресами: у разработчика — командой `load` в gdb, из браузера — со страницы. Программатор его не хранит | `swd-flash-py32f002b` |
| Область памяти | Диапазон адресов чипа, куда программатор вправе писать; у PY32F002B — основная flash и USER OTP | `swd-flash-py32f002b` |
| Единица стирания | Наименьший кусок области, который чип стирает за раз; у PY32F002B — страница 128 Б. Программатор стирает и пишет только единицы, где есть байты образа; байты такой единицы вне образа становятся стёртыми (`0xFF`) | `swd-flash-py32f002b` |
| Сеанс SWD | Время от подключения программатора к чипу до запуска платы обратно: сеанс gdb (от `monitor swdp_scan` или `attach` до `kill`, `detach`, закрытия порта или минуты тишины) или команда `info`. Вне сеанса программатор ноги SWD не держит | `swd-flash-py32f002b` |
| Способ подключения | Как программатор остановил чип: под сбросом или сразу после сброса | `swd-flash-py32f002b` |
| Итог | Последняя строка сеанса записи: `ок` или `ошибка` с причиной | `swd-flash-py32f002b` |
| USER OTP | Страница 128 Б по адресу `0x1FFF0280` для данных пользователя: полное стирание чипа её не трогает, `0xAA55` в младших 16 битах первого слова запирает её навсегда | `swd-flash-py32f002b` |
| Лог платы | Строки, которые прошивка платы пишет в свой UART; программатор выводит их в свой USB-порт | `swd-flash-py32f002b` |
| Страница прошивки | Веб-страница этого репозитория: через USB-порт программатора пишет в чип выбранные файлы Intel HEX, показывает итог и лог платы. Об изделиях не знает | `web-flash-page` |
| Страница изделия | Веб-страница, которую делает изделие в своём репозитории для своего производства; говорит с программатором так же, как страница прошивки | `web-flash-page` |
| Полное стирание | Стирание всей основной flash чипа по команде человека; USER OTP оно не трогает | `web-flash-page` |
| Метка файла | Короткая пометка напротив выбранного файла на странице: в какую область чипа, кроме основной flash, он пишет, или с какими файлами выше по списку пересекается | `jaffa-flasher-page` |
